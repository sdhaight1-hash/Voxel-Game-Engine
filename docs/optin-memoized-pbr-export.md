# Opt-in four-channel PBR export (issue #10, Phase 3)

The default **Export PBR maps** command is unchanged and renders albedo,
roughness, metallic, height and derived normal maps using the original
single-channel CPU renderer.

For an explicit experiment, launch the editor with
`VOXEL_MEMOIZED_PBR_EXPORT=1` and use the same **Export PBR maps** command.
The first four maps are then generated by
`Graph::render_channels_memoized_rgba(&[0,1,2,3],size,size)`, which shares
identical upstream f32 samples across requested output channels at exact UVs.
The fifth normal map **still** uses the established height-to-normal
function. All five filenames, resolution choices, overwrite safety and
pixel encoding stay unchanged.

Set `VOXEL_PROFILE_MATERIALS=1` as well to record a CPU-side
`memo_pbr_export` event with elapsed milliseconds, reused samples, evaluated
samples and peak per-pixel cache entries. The logged duration includes PNG
encoding and writes for the four memoized channels, so don't compare it
directly against the graph-only benchmark timings.

This is not a default behavior change. Existing tests establish byte
equivalence over the 1,039 material preset catalog and difficult warp/filter
graphs. Repeat export parity and performance measurements on the intended
desktop target before enabling it by default. No world, tree, GPU or voxel
material path is switched by this flag.
